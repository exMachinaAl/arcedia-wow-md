# Explorer Pack 04
Twelve small, text-first, standalone quiz mechanics added in v0.9.0. They reuse `challenge_sessions` and the existing reward ledger without introducing migrations. The existing **100 idea** catalog is still planning material, distinct from 48 playable prototypes. These games are not the same as full RPG/simulation game systems.

- primefactors: prime factor decomposition
- median: middle element of unsorted data
- mode: most frequent data item
- manhattan: grid-distance math
- perimeter: rectangle perimeter
- triangle: triangle area
- chance: simplified probability fraction
- utcwib: UTC → WIB timezone calculation
- divisible: integer divisibility
- caesar: shift cipher decoding
- a1z26: alphabet-to-number cipher
- setunion: union of integer sets

Rewards: 7 V per correct solution (capped by 100 V/day); no purchases or gambling. Tests cover replay protection, timeout, cap and cross-account isolation.
